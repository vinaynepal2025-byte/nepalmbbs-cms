# Nepal MBBS CMS 🏥

Welcome to the **Nepal MBBS AI Medical Education Ecosystem** Content Management System. This repository contains the core codebase for managing medical education data, student leads, and AI-driven automation.

## 📂 Project Structure
- `frontend/`: Flutter (Dart) application code for the user interface.
- `backend/`: Node.js (JavaScript) server, API routes, and automation engines.
- `wrc-tracker/`: Specialized tracking modules.
